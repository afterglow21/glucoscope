すでにGlurooを使っている方

Glurooにログイン済みなら、最初の設定は繰り返さなくて大丈夫です。

設定メニューを開くSTEPから始める

最初に

GlucoScopeをホーム画面へ追加します

1接続する前に

STEP 1

共有メニューを開きます

Instagramなどのアプリ内でこのページを開いている場合は、画面の「…」から共有メニューを開きます。Safariで開いている場合は、四角から上向き矢印が出ている共有ボタンを押します。

2接続する前に

STEP 2

Safariで開いて、ホーム画面へ追加します

「Safariで開く」が表示されたら、先にそれを押します。Safariでもう一度共有メニューを開き、「ホーム画面に追加」→右上の「追加」を押します。

「ブックマークに追加」ではありません。必ず「ホーム画面に追加」を選びます。

ここを確認ホーム画面にGlucoScopeのアイコンができたら準備完了です。

すでに同じGlucoScopeアイコンがある場合は、追加し直さず次へ進めます。初回のデータ接続は、最後にこのアイコンを開いて行います。

第5章

GlucoScopeへ貼る2つの情報をコピーします

33情報を守る

34画面中 33

Nightscout URLとAPI Secret Tokenをコピーします

各欄の右端にある重なった四角を押します。Nightscout URLはGlucoScopeの「接続先URL」へ、API Secret Tokenは「接続用の合言葉」へ貼ります。API Secret Header (SHA1)は使いません。

この2つは秘密の接続情報です

スクリーンショット、LINE、メール、SNSへ載せず、ご自身のGlucoScopeへ直接貼り付けてください。

公開用画像では、秘密の接続情報を隠しています。

34準備完了

34画面中 34

ホーム画面のアイコンからGlucoScopeを開きます

🍀 GlucoScopeの接続画面へ戻る
  1. iPhoneのホーム画面へ戻り、最初に追加したGlucoScopeのアイコンを押します。アイコンが見つからないときは、上の大きなリンクから開けます。
  2. 「データ接続（先行体験）」を押し、「Glurooでつなぐ」→「Glurooの準備ができたので、接続へ進む」の順に押します。
  3. 表示名を入力し、Nightscout URLを「接続先URL」へ、API Secret Tokenを「接続用の合言葉」へ貼ります。
  4. 「接続してGlucoScopeを始める」を1回押します。「接続を確認しているよ…」の間は、そのまま少し待ちます。
  5. 接続できると画面が自動で閉じ、「ようこそ、GlucoScopeへ 🍀」「接続できました。最新の血糖データを表示しています。」と短く表示されます。そのあと現在の血糖値画面が見えたら成功です。

URLや合言葉は、LINE・メール・SNSでほかの人へ送りません。エラーが出た場合は、Glurooから2つの情報をもう一度コピーして、同じボタンからやり直せます。

最後の確認

  • Glurooに自分の血糖値が表示されている
  • Nightscout URLをGlucoScopeの「接続先URL」へ貼った
  • API Secret Tokenを「接続用の合言葉」へ貼った
  • 接続情報をほかの人へ送っていない
画面が少し違うとき・SKIPの目安

Glurooのバージョンや仕様、言語・地域によって、画面の見た目、文言、順番、表示される画面が変わる可能性があります。見出しやボタン名が近いSTEPを探してください。

SKIPしてよい：インスリン設定、基礎インスリンのリマインダー、服薬リマインダー、Apple Health。
飛ばさない：ログイン、利用規約の確認、後半のCGM接続、Global Connect。

GlucoScopeは医療機器ではありません。治療判断、アラート、最新の機器状態は、元のCGM・ポンプアプリを確認してください。
