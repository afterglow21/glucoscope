Glurooを準備する方法

App Storeで探すところから、Nightscout URLとAPI Secret Tokenを確認するところまで、実際に表示された34画面を順番に案内します。

確認端末：iPhone 確認版：Gluroo 2.0.5 画面確認：2026年7月23日 全34画面

はじめに：画面が変わることがあります

このガイドは、2026年7月23日に確認したiPhone版Gluroo 2.0.5の画面をもとにしています。

Glurooのバージョンや仕様、使用しているCGM、選んだ回答、言語・地域によって、画面の見た目、文言、順番、表示される画面が変わる可能性があります。

同じ画面が見つからないときは、急いで入力せず、見出しやボタン名が近いSTEPを探します。治療に関する数値は、このガイドを見て入力・変更しません。

このガイドで使う「SKIP」の考え方

SKIPしてよい

インスリン設定、基礎インスリンのリマインダー、服薬リマインダー、Apple Health。

飛ばさない

CGM選択、ログイン、利用規約の確認、CGM接続、Global Connect。

通知はあとから変更できます。利用規約は内容を確認し、同意できる場合だけ進みます。

この案内の対象

FreeStyle Libre 2またはDexcom G7を使っている方のGluroo準備を、画面付きで案内します。

Guardian（MiniMed 780G）は、iPhoneのGuardian MonitorからGluroo Global ConnectへNightscout同期する方法を実機確認済みです。

Guardian MonitorからGlurooへつなぐガイドを見る

接続情報を守ります

Nightscout URLとAPI Secret Tokenは、GlucoScopeへ接続するための秘密の情報です。ほかの人へ送ったり、スクリーンショットへ写したりせず、自分の端末で直接コピー＆ペーストします。

公開用画像では、秘密の接続情報を隠しています。

途中から見返す

  1. App Storeから入れる
  2. 初回設定を進める
  3. CGMをつなぐ
  4. 設定を開く
  5. URLと合言葉をコピーする

第5章

GlucoScopeへ貼る2つの情報をコピーします

33情報を守る

34画面中 33

Nightscout URLとAPI Secret Tokenをコピーします

各欄の右端にある重なった四角を押します。Nightscout URLはGlucoScopeの「接続先URL」へ、API Secret Tokenは「接続用の合言葉」へ貼ります。API Secret Header (SHA1)は使いません。

この2つは秘密の接続情報です

スクリーンショット、LINE、メール、SNSへ載せず、ご自身のGlucoScopeへ直接貼り付けてください。

34準備完了

34画面中 34

GlucoScopeへ戻って貼り付けます

SafariでGlucoScopeの接続画面へ戻ります。Nightscout URLを「接続先URL」へ、API Secret Tokenを「接続用の合言葉」へ貼り、「つながるか確認する」を押します。URLや合言葉をLINE・メール・SNSで他の人へ送りません。

最後の確認

  • Glurooに自分の血糖値が表示されている
  • Nightscout URLをGlucoScopeの「接続先URL」へ貼った
  • API Secret Tokenを「接続用の合言葉」へ貼った
  • 接続情報をほかの人へ送っていない

GlucoScopeは医療機器ではありません。治療判断、アラート、最新の機器状態は、元のCGM・ポンプアプリを確認してください。
