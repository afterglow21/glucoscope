JP

問い合わせ方法

受付と返信

問い合わせ窓口：support@glucoscope.app

平日に受け付け、通常の問い合わせには原則として5営業日以内に返信します。土日祝日・年末年始は営業日に含みません。緊急対応や医療相談の窓口ではありません。

販売事業者の氏名・住所・電話番号を確認したい時は、件名または本文に「販売者情報の開示請求」と書いてください。購入の申込み前に確認できるよう優先して遅滞なく返信します。この請求に購入日や購入情報は必要ありません。

メールに書いてよいこと

  • 購入に使ったメールアドレスから送ってください。
  • おおよその購入日
  • 「二重決済」「Plusが始まらない」「大きな障害」「販売者情報の開示請求」「その他」のどれか
  • 困っている操作と、画面に表示された一般的なエラー内容

確認コードがすぐ届かない時

  1. コードの画面を閉じず、まず数分待ちます。
  2. 迷惑メール、プロモーションなどの分類、以前のGlucoScopeメールと同じ会話を確認します。
  3. 60秒の表示が終わった後、安全確認を新しく行い、「もう一度送る」を1回だけ押します。
  4. 再送した時は、いちばん新しいメールの6桁コードを10分以内に使います。

何度も続けて送らず、届かない時は問い合わせてください。6桁コードやメールのパスワードを送る必要はありません。確認できなくても、Freeの血糖表示は使い続けられます。

送らないでください

  • カード番号、セキュリティコード、Stripeやメールのパスワード
  • NightscoutやGlurooのURL、合言葉、API Secret
  • 血糖値の一覧、治療内容、インスリン量、医療機器の設定
  • 子どもの氏名、生年月日、学校名など、購入確認に不要な個人情報

GlucoScopeから、これらの情報をメールで求めることはありません。

返金の流れ

  1. 問い合わせを受け取り、購入メール、おおよその購入日、JPY 400の支払いを最小限の情報で確認します。
  2. 二重決済やPlus未付与は、可能なら先に訂正します。
  3. 訂正できない場合、または返金条件に当てはまる大きな障害を解決できない場合は、Stripeで全額返金します。
  4. 異議申立てが進行中の場合は通常の返金を重ねず、Stripeの異議申立て手順で確認します。
  5. 返金した支払いに対応するPlusを終了し、成功・処理中・失敗を区別して返信します。

部分返金は行いません。支払元への反映には通常5〜10営業日ほどかかる場合があります。

医療に関する相談

診断、治療、インスリン量、薬、CGMやポンプ設定、急な症状には回答できません。元のCGM・ポンプ画面を確認し、必要な時は医療機関へ相談してください。

English summary

Contact boundary

The public address is support@glucoscope.app, weekdays, with a target response within five business days. Forwarding and real receipt from a separate sender are confirmed.

Send from the purchase email and include only the approximate purchase date, request category, affected action, and general error wording. Never send card details, passwords, Nightscout or Gluroo credentials, glucose records, insulin information, or device settings. This is technical and purchase support, not medical or emergency support.

If a verification code is slow, keep the code screen open for a few minutes and check junk, categories, and the existing GlucoScope thread. After the 60-second wait, complete a fresh safety check and resend only once. Use only the newest email after a successful resend. Never send the six-digit code or email password to support. Free glucose viewing remains available.
