現在の技術課題

Friends & Family Preview、AI利用カウンター、共有KVキャッシュ、CORS制限、Trust Pack、Web Analytics、初回告知まで進みました。一般利用者向けの最初の実機確認では、途中画面をまとめたガイドだけでは一人で進めにくく、SKIPする画面とアプリの見分け方を一画面ずつ案内する必要があることが分かりました。現在は、Glurooの全画面チェックポイントと、FreeStyle LibreLink・LibreLinkUp・Glurooを見分ける案内へ改訂しています。

既存Nightscoutのブラウザ直接接続は確認済みです。Gluroo Global Connectは、接続先と取得内容を限定したCloudflare Workerでの到達確認、Guardian MonitorからGlurooへの実機送信、Turnstile、約1時間の接続チケット、回数制限まで完成しました。停止状態のWorker、Durable Object、必要なSecretに加え、停止確認用の公開先も1つ作成しました。公式資料の確認から、提供元の返答は歓迎しつつも、返答がないことだけを公開停止条件にはしない方針としました。GlucoScopeの画面には分かりやすい同意表示を追加し、停止中の公開先へ固定した状態でPC・スマホの案内を確認しました。Trust Packと設定・安全性の最終確認も完了し、別の承認を得た停止状態の確認デプロイ後も、停止応答、CORS、Secret名、Durable Objectを確認しました。リレーは無効のままで、実データには接続しません。現在は、Guardian Monitorから始まる最初の候補ルートについて、GlucoScopeまでの全経路の実機受け入れと、有効化についての別の明示的な承認を残しています。確認が終わっていないLibre・Dexcomなどは確認済みとは案内しません。

User Foundation

The current phase is revising onboarding from real-device feedback: each optional screen needs an explicit step, app switches need exact app identification, and a participant should be able to proceed without live coaching.

Existing Nightscout browser access is verified. The paused Gluroo-only relay now has verified Worker reachability, a Guardian Monitor input segment, server-side Turnstile, short-lived tickets, request limits, a stopped Worker shell, a Durable Object, the required Secret bindings, and one stopped-state public target. The official-materials, final Trust Pack, and final configuration and security reviews are complete. A separately approved stopped validation deployment also passed the paused-response, CORS, Secret-name, and Durable Object checks without real data. GlucoScope shows explicit consent and was checked in desktop and mobile layouts while fixed to the stopped target. The relay remains disabled and cannot access live data while end-to-end acceptance for the first Guardian candidate route and separate explicit live-enablement approval remain. Libre, Dexcom, and other routes will not be described as verified until their own checks pass.

Community & Sustainability

One-time optional development support is now available without changing features or access. GlucoScope will continue to grow with the community and explore ethical ways to keep the project running.
