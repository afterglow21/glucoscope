# GlucoScope Plus 販売表示・返金方針 内部ドラフト

Status: internal draft / non-public / not approved for sale

Last reviewed: 2026-08-15

この文書は、GlucoScope Plus 30日パスを販売する前に、通信販売の表示、最終確認画面、返金、障害対応、税、領収書を整理するための内部テンプレートである。法律・税務上の結論ではなく、空欄の入力、運営者本人の承認、必要な専門家確認がすべて終わるまで販売用の確定文面として扱わない。

## 1. ステータスの読み方

| 表示 | 意味 |
| --- | --- |
| **確定済み** | Plusの商品仕様として承認済み |
| **推奨候補・未承認** | 安全な初期販売のための案。運営者承認と必要な専門家確認が終わるまで確定ではない |
| **本人入力** | 販売者本人が正確な情報を記入する。推測や屋号だけで埋めない |
| **専門家確認** | 税務署、税理士、弁護士その他の適切な窓口へ、実際の販売方法と画面を示して確認する |

## 2. 確定済みの商品仕様

| 項目 | 確定内容 | 補足 |
| --- | --- | --- |
| 商品名 | GlucoScope Plus 30日パス | 有料の追加機能を一定期間使うサービス |
| 価格 | 300円 | 「最終支払総額300円」とする案は税務確認前の候補 |
| 支払い | 1回払い | 定期購入、分割継続課金ではない |
| 利用期間 | Stripeの決済成功から連続30日 | 利用者へ終了日時を分かりやすく示す |
| 自動更新 | なし | 期限後に自動請求しない。続けたい人だけが新たに購入する |
| 決済事業者 | Stripe | Stripeが提供する決済画面を利用する |
| サービスの性質 | 医療サービスではない | 診断、治療判断、インスリン量、薬、医療機器設定、緊急時の判断を提供しない |

購入によって、より正しい医療判断、より良い血糖値、治療効果または健康上の効果が得られるとは案内しない。

## 3. 返金の決定と、その他の未承認候補

次のうち、購入者と返金に関する行は運営者本人が承認した運営方針である。それ以外は、まだ承認していない安全側の候補である。返金方針も、公開問い合わせ先と実際の受付手順、公開文面の確認が終わるまでは販売用の確定ページとして公開しない。

| 項目 | 内容 |
| --- | --- |
| 販売地域 | 日本国内に居住する人だけを初期販売対象とする |
| 決済方法 | 初期は、支払い結果をその場で確認できるカード決済だけにする |
| 最終価格 | 利用者が支払う総額を300円とし、追加のGlucoScope料金を加えない |
| 税の表示 | 税務確認後に、適切であれば「300円（税込）」と表示する。確認前は「お支払い総額300円」とする |
| 購入者 | 購入とメールを管理する18歳以上の本人、または子どもの購入・復旧・問い合わせを管理する18歳以上の保護者 |
| 返金方針 | 二重決済やPlus未付与を訂正できない場合、またはGlucoScope側の大きな障害で主要特典をほとんど利用できず運営側でも解決できない場合は、状況確認後に全額返金する。部分返金は行わず、返金したPlusは終了する |
| 返金の反映 | カード会社等への反映は通常5〜10営業日程度かかる場合があると案内する |

「大きな障害」を分単位・時間単位のSLAや長い除外一覧にはしない。主要特典をほとんど利用できなかったことと、運営側でも復旧できなかったことを、問い合わせごとに確認する。公開問い合わせ先と返金受付手順が未定のため、現時点では販売しない。

## 5. 専門家確認が必要な項目

- 個人開発者としての課税・免税の区分と、消費税の記帳・申告方法
- 300円を最終支払総額にする場合の「税込」表記
- Stripe Taxを利用する必要性、必要な税務登録、正式な商品税コード、Priceの税の扱い
- 適格請求書発行事業者の登録有無と、交付する書類の名称・記載事項
- 個人事業者の氏名、住所、電話番号の表示方法。バーチャルオフィス等を使う場合の要件
- 二重決済・未付与の訂正または全額返金、GlucoScope側の大きな障害、部分返金なし、返金後終了という短い方針の表示と運用
- 18歳未満から直接購入を受けない初期方針と、誤購入時の対応
- 日本国外から購入を受けない方法。将来国外販売する場合の各国・地域の税務と消費者保護
- 問い合わせ、返金、異議申立て、領収書に必要な記録と保存期間

## 7. 返金・障害対応の方針

消費者庁は、通信販売には訪問販売等で認められる一般的なクーリングオフ規定はないと説明している。一方で、申込みの撤回・解除条件は具体的に表示する必要がある。「クーリングオフなし」を理由に返金条件を省略せず、このサービスの条件を販売前に確定する。

### 7.1 利用者へ示す短い文面案

> 二重に支払われた時や、お支払い後もPlusを始められない時は、状況を確認して直します。こちらで直せない場合は、全額返金します。GlucoScope側の大きな障害で、Plusの主な機能をほとんど使えず、こちらでも解決できない場合も、状況を確認して全額返金します。部分返金は行いません。返金したPlusは終了します。カード明細への反映は、カード会社や銀行により通常5〜10営業日ほどかかる場合があります。

### 7.2 内部運用の境界

- 二重決済やPlus未付与は、まず運営側で訂正し、利用者へ再購入を求めない。訂正できない場合は全額返金する。
- GlucoScope側の大きな障害は、Plusの主要特典をほとんど利用できず、運営側でも解決できない場合を指す。分単位・時間単位のSLAや細かな除外一覧にはせず、記録を確認して個別に判断する。
- それ以外の相談も受け付けるが、利用者都合を含むすべての申出を同じ返金対象とは約束しない。
- 部分返金は行わない。全額返金を始めた支払いに対応するPlusは終了する。
- 問い合わせでは、血糖値、CGM接続情報、カード番号、パスワードの送付を求めない。購入を確認できる最小の参照情報だけを案内する。

返金をStripeで開始してからカード明細へ反映されるまで、銀行やカード会社により通常5〜10営業日程度かかる場合がある。これは反映の目安であり、GlucoScopeが到着日を保証する表現にはしない。返金済み、処理中、失敗を見分け、問い合わせへ説明できる手順を販売前に用意する。

## 8. 最終確認画面に表示する項目

Stripeへ移動する直前の画面を、明確に「お申し込み内容の最終確認」と表示する。重要事項を折りたたまず、支払いボタンより上で簡単に確認できるようにする。

- 商品名：`GlucoScope Plus 30日パス`
- 数量：`1`
- お支払い総額：`300円`。税務確認後、適切であれば`300円（税込）`
- 支払方法：実際に受け付ける方法をすべて表示
- 支払時期：実際の決済方法に合わせて表示
- 利用開始時期：支払い成功後の具体的な時間または期限
- 利用期間：Stripeの決済成功から連続30日
- `1回払い`と`自動更新なし`
- 二重決済・Plus未付与を訂正できない場合と、GlucoScope側の大きな障害を運営側でも解決できない場合の、全額返金方針の短い要約
- 部分返金なし、全額返金した支払いに対応するPlus終了
- 販売地域・年齢など、購入できる人の条件
- 医療サービスではなく、診断や治療判断を提供しないこと
- 「特定商取引法に基づく表記」、利用規約、プライバシー、問い合わせ先への分かりやすいリンク
- 入力内容を戻って訂正する手段と、購入をやめる手段

主ボタンの候補は`300円を1回支払う`、戻るボタンの候補は`今は購入しない`とする。`続ける`、`登録する`、`購読する`など、支払いまたは自動更新の有無が分かりにくい言葉を使わない。

Stripeの決済画面でも、商品名、価格、1回払い、自動更新なし、販売者情報、規約・プライバシーへの案内が自前の最終確認画面と矛盾しないことを確認する。

## 9. 最終確認画面の短い文面候補

**推奨候補・未承認**

> GlucoScope Plus 30日パスは、300円の1回払いです。自動更新はありません。お支払いを確認した時から30日間使えます。期限が来ても自動で料金は発生しません。GlucoScopeは医療サービスではなく、診断や治療の判断はしません。

税務確認が終わり、利用者が支払う最終額が300円であることを確認できた場合は、最初の文を次の候補へ変更する。

> GlucoScope Plus 30日パスは、300円（税込）の1回払いです。

公開問い合わせ先と受付手順を用意し、公開文面を確認できた場合だけ、次を追加する。

> 二重に支払われた時や、お支払い後もPlusを始められない時は、状況を確認して直します。こちらで直せない場合は、全額返金します。GlucoScope側の大きな障害で、Plusの主な機能をほとんど使えず、こちらでも解決できない場合も、状況を確認して全額返金します。部分返金は行いません。返金したPlusは終了します。

## 10. Stripe、税、領収書の確認

### Stripe Tax

- Stripe Taxの利用有無を、課税・免税の区分と販売地域を確認してから決める。
- Stripe Taxを利用する場合は、必要な地域で税務登録が有効になっていることを先に確認する。
- 商品に合う正式な商品税コードをStripeの一覧から選び、専門家に確認する。コードを推測しない。
- 300円を最終支払総額に保つ場合は、Priceの税の扱いをinclusiveにする候補を確認する。inclusiveまたはexclusiveに設定したPriceは後から変更できないため、決定前に確定しない。
- 決済画面と領収書の最終額が、自前の価格表示と一致することを確認する。

### 領収書

- Stripeの成功決済・返金領収書に、商品名、金額、販売者名、問い合わせ先、返金状態が正しく出ることを確認する。
- Stripeの通常領収書を、自動的に「適格請求書」と呼ばない。
- 適格請求書発行事業者として登録済みで、必要事項を満たすことを確認できた場合だけ、適格請求書として案内する。
- 登録していない場合は登録番号欄を空欄にし、架空、類似、他者の番号を記載しない。
- 決済のためStripeがメールアドレスと決済情報を扱うこと、GlucoScopeはカード番号を保存しないことを、プライバシー説明と一致させる。

## 11. 販売前の停止条件

次のどれか1つでも未完了なら販売しない。

- [ ] 販売事業者の氏名または登記商号、所在地、電話番号、問い合わせ先が確定している
- [ ] 個人事業者としての表示方法を確認している
- [ ] 課税・免税、300円の最終総額、税込表記、税務登録、商品税コードを確認している
- [ ] 適格請求書発行事業者の登録有無と、領収書の案内を確認している
- [x] 二重決済・Plus未付与を訂正できない場合と、GlucoScope側の大きな障害を運営側でも解決できない場合は全額返金する方針を、運営者本人が承認している
- [ ] 上の返金方針を、短い公開文面と実際の受付手順へ落とし込んでいる
- [ ] 問い合わせ方法、返信目安、返金処理、異議申立て対応を実際に行える
- [ ] 販売地域、年齢、決済方法の条件を確定し、利用者へ分かりやすく表示している
- [ ] 最終確認画面で、総額、1回払い、30日、自動更新なし、提供時期、返金条件を一覧できる
- [ ] 戻る、訂正、購入中止の手段を確認している
- [ ] Stripeの決済画面と領収書が、自前の説明と一致している
- [ ] 実際の販売画面、通信販売表示、返金条項を必要な専門家へ一式で確認している
